# StockWise-ML Streamlit app

## Deploy
1. Upload the contents of this folder to the root of your GitHub repository.
2. In Streamlit Community Cloud choose repository `dhruvrana1905-source/StockWise-ML`, branch `main`, main file `app.py`.
3. Deploy.

## Dataset note
The included `data/demo_stock_data.csv` is synthetic demonstration data, not live exchange data.
The app is an educational demonstration and not investment advice.
